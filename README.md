# Cadenas Mysterieux
L'idée principale consiste à déverrouiller un coffre grâce à des énigmes sous forme de mini-jeux. Deux puzzles doivent être résolus afin d'obtenir les différentes parties du code nécessaires pour ouvrir le coffre.

## Scène puzzle
Il y a 3 chiffres à trouver. Chaque puzzle réussit révèle le code nécessaire pour débloquer le prochain puzzle.
### technologies utilisée
1- Le bouton : permet de valider le puzzle.
2- Le slider : permet de trouver les elements du puzzle.

Concept visuelle :
- 1er puzzle : utiliser le slider pour trouver le premier chiffre.

La transition entre la scène du puzzle à la scene du cadenas se fera automatiquement lorsque l'utilisateur à débloquer les 3 puzzle.
